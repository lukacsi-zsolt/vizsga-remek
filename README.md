# Szárnysegéd

## Projekt ismertető

A **Szárnysegéd** egy közösségi webalkalmazás siklóernyősök számára, amelynek célja, hogy egy helyen biztosítson információkat, kommunikációs lehetőségeket és térképes funkciókat a repülési helyszínekről.

A rendszer lehetővé teszi a felhasználók számára:
- repülési helyszínek (spotok) böngészését egy interaktív térképen
- új helyszínek javaslatát
- fórumon való részvételt (posztok létrehozása, kommentelés)
- hírek megtekintését és követését
- saját profil kezelését

Az admin felület segítségével a rendszer teljes körűen menedzselhető:
- felhasználók kezelése
- spotok és spot javaslatok elfogadása/törlése
- hírek létrehozása és törlése
- fórum tartalmak moderálása
- statisztikák megjelenítése (pl. aktivitás az elmúlt 7 napban)

## Fő funkciók

- **Interaktív térkép (Mapbox)**  
  Repülési helyszínek megjelenítése, széladatok lekérdezése, navigáció

- **Fórum rendszer**  
  Bejegyzések, képfeltöltés, helyszín címkék, keresés és szűrés

- **Felhasználói profilok**  
  Egyedi profiloldalak, statisztikák, követési rendszer

- **Hírek modul**  
  Közösségi és információs tartalmak megjelenítése

- **Admin felület**  
  Teljes rendszerkezelés egy központi dashboardon keresztül

## Technológiák

- **Frontend:** Blazor Server
- **Backend:** ASP.NET Core Web API
- **Adatbázis:** Entity Framework Core (SQL)
- **Térkép:** Mapbox
- **Grafikonok:** Chart.js
- **Stílus:** Egyedi CSS (reszponzív kialakítás)

## Cél
